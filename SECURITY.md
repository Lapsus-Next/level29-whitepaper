# Security Policy

## Supported Versions
We release patches as needed. Only the latest version is actively maintained.

| Version | Supported |
| -------- | ---------- |
| latest   | ✅ |
| older    | ❌ |

## Reporting a Vulnerability
If you discover a security vulnerability, please **do not open a public issue**.

Instead, email us at **security@level29.games** with details of the issue.
We’ll review your report and respond as soon as possible.

Thank you for helping us keep Level29 Games and its players secure!
